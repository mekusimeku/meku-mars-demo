ABOUT THE RESEARCH

Proof before action.

The local Python Genesis core has separate SQLite stores, Ed25519-signed messages, durable queues, evidence, simulated human decisions and resource rules. This public page runs a smaller deterministic model in your browser. It carries no Python keys or databases and does not control equipment.

The paired results below were generated by the Python core, then saved as static data. Neither the browser run nor a successful simulation proves a Mars habitat is safe. We will test evidence selection with synthetic Earth and Mars formats before using field data.
